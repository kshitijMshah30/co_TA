## Ethar Mostafa - Week 9 Progress

### Overall Progress

This week, I worked on making the interface more modular so that it can support multiple courses rather than being designed for only one. For example, TAs can now add new courses, enable or disable course-specific features based on their needs, upload course labs, and set a class password. They can also provide lab steps and learning objectives for students to view. Students can then join multiple courses using the appropriate class password and access the labs uploaded by the TA, while being restricted from uploading their own lab materials.

### Current Blockers

My main blocker is deciding what additional features are needed to make the system flexible enough to support a wider variety of courses and lab structures.

### Plans for Next Week

Next week, I plan to add more features that improve the student experience and make the system useful across different types of courses. For example, I want to explore adding reference tools similar to the resistor color-code tab, such as tools for capacitors or inductors. I also plan to explore allowing TAs to upload datasheets for commonly used components or microprocessors, since some courses use the same hardware throughout the semester. This would give students easy access to important course-specific reference materials directly within the interface.
